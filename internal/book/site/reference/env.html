Environment variables

orq

VariableDefaultMeaning
MODEemptydev serves swagger to anyone and allows session cookies over plain http. Otherwise only someone signed in on the Maestro page sees swagger.
MAESTRO_ORQ_ADDR:8081Where orq listens. The compose file uses :3005.
MAESTRO_ORQ_DBmaestro-orq.dbThe SQLite database
ALLOWED_ORIGINSrequiredThe origins of the Maestro page, separated by commas, for CORS
VIEW_URLThe first of ALLOWED_ORIGINSWhere the Maestro page is served. Sign-ins return there.
PODMAN_SOCKETunix:///run/podman/podman.sockorq's own Podman, which builds images
BUILD_TIMEOUT30mHow long a build may take
ALLOWED_FORGE_HOSTSgithub.com,codeberg.org,gitlab.comThe only hosts orq clones from. The list keeps anyone from pointing orq at a host on its own network.
DATA_DIR/maestro/dataWhere the logs and outputs of runs are kept
RUN_OUTPUT_MAX_MB1024The logs and outputs kept for each line. orq drops the rest and leaves a note on the line.
RUN_MAX_HOURS168 (a week)How long a line may run. orq stops a line that runs longer, keeps its logs and outputs, and ends it as error. 0 means no limit.
RUN_PIDS512The limit on processes in each container. 0 means no limit.
REDIS_URLrequiredredis://[:password@]host:port/db of a Redis, Valkey or KeyDB
SESSION_TTL12hHow long a session of the Maestro page lasts
KEY_TTL2160h (90 days)How long a Maestro key works after it was issued. 0 means keys never expire.
COOKIE_SECUREtrue, or false with MODE=devSet it to false only when you serve over plain http.
OIDC_ISSUERrequiredThe issuer URL. It must serve /.well-known/openid-configuration.
OIDC_CLIENT_IDrequired
OIDC_CLIENT_SECRETrequired
OIDC_REDIRECT_URLrequired<orq>/api/auth/callback, as registered with the provider
OIDC_SCOPESopenid email profileSeparated by spaces
OIDC_ROLES_CLAIMrolesThe ID token claim that holds the user's roles, as a string or a list
OIDC_ALLOWED_ROLESemptySeparated by commas. When empty, anyone the provider authenticates can sign in.
OIDC_ADMIN_ROLESADMINThe roles that make a user an administrator, separated by commas
ADMIN_EMAILSemptyEmails of users who are administrators whatever their roles, separated by commas
MACHINE_SECRETemptyEncrypts the stored SSH keys. At least 32 characters. While it is empty, machines are turned off.
MACHINE_PROXY_COMMANDSfalseAllows machines reached through a proxy command, which runs on the orq server

Deploying Maestro and The identity provider say which of these a new deployment has to set.

The CLI

VariableMeaning
MAESTRO_ORQ_URLThe Maestro server to use in place of the one the CLI kept. --server wins over it.
MAESTRO_DOCS_URLWhere maestro docs opens this book, in place of the copy inside the CLI or, with --web, the server's /docs
NO_COLORPrints without colours, as --no-color does

Inside each container

orq sets these after the run's own env. Inside the container shows how a program uses them.

VariableValue
MAESTRO_RUNThe run's number
MAESTRO_LINEThe line's number in the run, starting at 1
MAESTRO_CPUSThe line's cpus
MAESTRO_MEMORYThe line's memory, in MB
MAESTRO_OUTPUTSThe line's outputs, one path on each text line
